# ステラ☆ランブル 〜ワールドアイドル大乱闘〜

スマホの横画面で遊ぶ、ファイナルファイト／ベアナックル風のベルトスクロールアクション。
日本の新人アイドルユニット「ステラ☆ライン」を操作して、心を奪われた世界中のアイドルたちを
ライブ（物理）で正気に戻しながら、ソウル → ニューヨーク → ロンドン → リオ → パリ → 東京ドームを巡る。

画像・音声ファイルは一切使わず、キャラクター・背景は Canvas の図形、BGM・効果音・掛け声は Web Audio で
その場で合成している。ビルド不要で、`index.html` を開くだけで動く。

## 遊び方

- 画面左側：どこを触ってもそこがスティックになる（同じ向きに倒し続けるとダッシュ）
- **A** こうげき（連打でコンボ、ダッシュ中はダッシュ攻撃、ジャンプ中は空中攻撃）
- **B** ジャンプ（ハナは二段ジャンプ）
- **S** ひっさつ技：そのまま／→+S／ジャンプ中S で 3 種類。SP（★）を 1 つ使う。足りないと HP を少し使う
- **★** 超必殺技：SP が 3 つたまると光る。カットイン付きで画面全体を攻撃
- つかみ：敵に向かって歩くとつかむ → A でひざ蹴り 2 回＋投げ、逆方向+A で後ろ投げ。投げた敵は他の敵に当たる
- 箱・スピーカーを壊すと、ご当地フード（回復）・サイン色紙・トロフィー・ペンライト（SP）・1UP が出る
- PC：矢印/WASD 移動・Z こうげき・X ジャンプ・C ひっさつ・V 超必殺・P ポーズ

## ステージとボス

| | ステージ | ボス | 主な技 |
|---|---|---|---|
| 1 | ソウル・ネオンストリート | K-POP ダンスクイーン ハン・セラ | 3 連キック、ダッシュキック、（後半）スピンストーム |
| 2 | ニューヨーク・ブロードウェイ | ブロードウェイの歌姫 ロキシー | マイクスタンド、突進、衝撃波、（後半）応援団の呼び出し |
| 3 | ロンドン・レイニーナイト | ロンドン・ロックの女王 ヴィクトリア | ギター叩きつけ、音符弾、ステージダイブ |
| 4 | リオ・カーニバル | カーニバルの太陽 ルシア | 旋回ダンス、扇のブーメラン、ストンプ |
| 5 | パリ・ランウェイ | パリコレの女神 エトワール | 日傘突き、薔薇投げ、日傘で浮遊→急降下、（後半）ワープ |
| 6 | 東京ワールドアイドルドーム | 伝説のアイドル オーロラ | マント払い、王冠ビーム、スポットライト落下、（後半）床を走るレーザー（ジャンプで回避） |

ボスは体力が半分を切ると本気モードになり、技が増えて速くなる。
雑魚敵は 5 タイプ（ダンサー・チア・パワー型の突進・ペンライト投げ・スライディング）で、ステージごとに衣装と名前が変わる。
倒した敵は正気に戻って手を振りながら去っていく。

全 6 ステージで、総プレイ時間は 25〜30 分程度を想定（自動操作のテストでは 33〜42 分。人が遊ぶほうが速い）。
ステージをクリアすると「つづきから」でそのステージから始められる。コンティニュー時にアイドルを変えることもできる。
設定で難易度「かんたん」（受けるダメージ・ボスの体力が少なめ）にできる。

## 音

- BGM：曲ごとに「テンポ・キー・コード進行（王道進行・カノン進行など）・ドラムの型」を決め、メロディは乱数の種から自動作曲。
  サビではベル（グロッケン）が重なり、観客の「ハイ！ハイ！」コールが入る。
  ステージ曲 6 曲＋ボス曲・ラスボス曲・タイトル・エンディング
- 掛け声：フォルマント合成で「ハッ！」「えいっ！」「きゃっ！」などをキャラごとの声の高さで鳴らす
- セリフ：端末の日本語読み上げ（Web Speech API）で、キャラごとに声の高さと速さを変えて話す。
  字幕も出るので、読み上げがオフ・非対応の端末でも内容はわかる（設定でオン／オフ）

## 起動

```sh
python3 -m http.server 8000
# スマホから http://<PCのIP>:8000/stella/ を開いて、横向きにする
```

GitHub Pages ではリポジトリの `/stella/` で公開される。iPhone は「ホーム画面に追加」すると全画面で遊べる。

## ファイル構成

- `js/figure.js`：キャラクターを図形で組み立てて描く（姿勢・髪型・衣装・小物）
- `js/audio.js`：BGM の自動作曲と再生、効果音、掛け声の合成、読み上げ
- `js/data.js`：キャラクター・技・敵・ボス・ステージのデータ
- `js/bg.js`：6 都市の背景（視差スクロール、タイルにキャッシュ）
- `js/core.js`：画面サイズ、タッチ操作、保存、文字、パーティクル
- `js/combat.js`：状態遷移、技、当たり判定、つかみ・投げ、敵とボスの AI、飛び道具、超必殺技
- `js/stage.js`：ステージ進行（ウェーブ・カメラ・アイテム・ボス戦）と HUD
- `js/scenes.js`：タイトル・キャラ選択・ストーリー・設定・ポーズ・コンティニュー・エンディング、メインループ

動作確認用の URL パラメータ：`?stage=3&char=luna`（そのステージから）、`&god`（無敵）、`&bot`（自動操作）、`&fast=4`（早送り）
