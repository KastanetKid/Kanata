# Kanata — Endless Stair

白黒ドット（1bit ディザ）で描かれた、終わりのない階段をひたすら登る縦画面スマホゲーム。

## 遊び方

- 次の段がある側（左上 / 右上）の画面半分をタップすると一段登る
- 段のない側をタップすると落下してゲームオーバー
- 上のゲージは時間とともに減り、登ると回復する。スコアが上がるほど減りが速くなる
- PC では ← / → キーでも操作できる

## 起動

ビルド不要。`index.html` をブラウザで開くだけで動く。
スマホで遊ぶ場合は、静的ホスティング（GitHub Pages など）に置いてアクセスし、
「ホーム画面に追加」するとフルスクリーンで遊べる。

ローカルでスマホから試すなら:

```sh
python3 -m http.server 8000
# 同じ Wi-Fi のスマホから http://<PCのIP>:8000 を開く
```

## 仕組み

- `game.js` が 108px 幅の低解像度キャンバスにグレースケールで描画し、
  毎フレーム 4x4 ベイヤー行列でディザをかけて 2 色に変換 → CSS で拡大表示
- 階段は左右ジグザグにランダム生成（同じ向きは最大 6 段まで）
- ベストスコアは `localStorage` に保存
