# Kanata — Endless Stair

白黒ドット（1bit ディザ）で描かれた、終わりのない階段をひたすら登る縦画面スマホゲーム。

## 遊び方

- タイトルでタップすると、次の小節の頭から拍に合わせて「3・2・1・START!」。START! の拍からノーツが流れ、操作できる
- 画面の左半分 / 右半分をタップして移動する
  - その側に次の段があれば一段登る
  - その側に前の段があれば一段下る（曲がり角では次の段と前の段が同じ側にあるので、登るほうが優先）
  - どちらの段もない側をタップすると落下してゲームオーバー
- 画面下のノーツレーン：左右から飛んでくるノーツが中央の枠で重なる瞬間がビート（音なしでも遊べる）。
  ノーツは拍に合わせて震える
- BGM（128 BPM、一定）の拍に合わせてタップするとコンボが増える。100 段を越えると次の小節から 140 BPM にテンポアップ
  - 拍から ±85ms 以内で GREAT、±130ms 以内で GOOD
  - 拍から外れたとき、同じ拍に 2 回タップしたとき、拍を 1 つ飛ばしたときはコンボが 0 に戻る
- 20 コンボで FEVER：画面がプリズム色になり、拍ごとに画面が揺れて紙吹雪が舞い、BGM に音が増える
  - FEVER 中にコンボが切れると、一瞬で白黒の通常モードに戻る
- 上のゲージは時間とともに減り、登ると回復する（拍に合っているほど多く回復）
- 自動スクロール：START 後の最初の一歩から、画面がゆっくり上がっていく（最初は 4 拍で 1 段、高く登るほど少しずつ速くなり最大 3 拍で 1 段。テンポアップ後は拍が短くなるぶん速くなる）
  - 登っている間は画面が主人公についてくる。止まったり下ったりすると主人公が画面の下へずれていく
  - 沈んでくると画面の下が赤く光って警告音が鳴り、ノーツレーンの上の赤い線まで沈むと TOO SLOW でアウト
  - 目安：スクロールだけなら完全に止まって約 17 拍でアウト（ゲージは約 13 拍で尽きる）
- 8 段を越えると色付きの敵が出てくる。当たったら一発で K.O.
  - 紫のクラッシャー：先の段の上で残り拍数を見せて予告し、拍に合わせて落ちてきて 1 拍居座る。
    拍どおりに「下る → 上る」を繰り返せば、コンボを保ったまま通り過ぎるのを待てる
  - 赤いコウモリ：画面端の「!」と点線で通り道を予告し、その段の高さを横切る。上か下の段へ逃げて避ける
- 12 段を越えるとアイテムが少し先の段に出てくる（同時に 1 つまで）
  - 拍の裏（拍と拍の真ん中）ごとに、主人公の 2 段下〜5 段上の範囲で 1〜2 段ずつぴょんと跳ね回る
    （今いる段とクラッシャーの段には降りない）。着地先の段には小さな影が出る
  - アイテムがいる段に乗ると取れる。14 拍で消える（最後の 3 拍は点滅）
  - ★ 無敵スター（7 秒）：敵に当たると逆に倒せる（SMASH!）。タイミングに関係なくタップは全部 GREAT 扱いで、
    連打でコンボを稼げる。段のない側をタップしても落ちず、ゲージも減らない。体が虹色に光る
  - 羽つきの靴（5 秒）：拍に合わせたときのコンボの増え方が 2 倍。足もとに羽がつく
  - 右上に効果の残り時間バーを表示
- スコアはそれまでに稼いだコンボの合計（コンボが切れても減らない。羽の靴中は 1 回で +2）。
  右上の旗の下に小さく最高コンボを表示
- ゲームオーバー後に結果発表（スコアのカウントアップ、最高コンボ、ベスト更新）があり、タップでタイトルに戻る
- 敵・アイテムの出現、ゲージの減り方、テンポアップは到達した高さ（段数）で決まる
- PC では ← / → キーでも操作できる

## 起動

ビルド不要。`index.html` をブラウザで開くだけで動く。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
「Deploy from a branch」→ `main` / `/ (root)` を選ぶ（`.nojekyll` 入り）。
スマホで遊ぶ場合は、静的ホスティング（GitHub Pages など）に置いてアクセスし、
「ホーム画面に追加」するとフルスクリーンで遊べる。

ローカルでスマホから試すなら:

```sh
python3 -m http.server 8000
# 同じ Wi-Fi のスマホから http://<PCのIP>:8000 を開く
```

## 仕組み

- `music.js` が Web Audio で BGM を 16 分音符単位に先読みで鳴らし、拍の時刻を記録する。
  タップ時刻と一番近い拍の時刻の差でリズム判定する（出力遅延の分は差し引く）。
  描画が重くても音が遅れないよう 0.35 秒先まで予約する。
  ノーツ表示と判定は `AudioContext.getOutputTimestamp()`（非対応なら currentTime − 出力遅延）から
  「今鳴っている音の時刻」を求め、1 フレームに 1 回だけなめらかに補正した時計を使う。
  カウントダウン開始時に時計を測り直すので、リプレイを重ねてもずれが溜まらない
- `game.js` が 108px 幅の低解像度キャンバスにグレースケールで描画し、
  毎フレーム 4x4 ベイヤー行列でディザをかけて 2 色に変換 → CSS で拡大表示
  - 背景・壁・支柱・幽霊だけディザで描き、階段の踏み面と手すり、主人公（金色）、敵、ノーツは
    ディザの後にベタ塗り＋黒ふちで描くので、通常時もフィーバー時もくっきり見える
  - フィーバー中は背景のプリズムを暗めにし、階段の蹴込みを段ごとの色にする
- 階段は左右ジグザグにランダム生成（同じ向きは最大 6 段まで）
- ベストスコアは `localStorage` に保存
