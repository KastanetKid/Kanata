# まとめたやーつ（カジュアルゲーム モック集）

縦画面・片手で遊べるモック 10 本。ビルド不要で、リポジトリ直下の `index.html` がポータル「まとめたやーつ」
（GitHub Pages ならサイトのトップ）。

| ゲーム | ジャンル | 面白さの核（リスクとリターン） |
|---|---|---|
| ニクハク | シューティング | 敵に近いほど弾が ×3。当たる距離は当てられる距離 |
| ツナギ | パズル | 長くつなぐほど得点は二乗。探している間も時間は減る |
| ガケピタ | はじき | 崖のふちに近いほど高得点。行きすぎたら落ちる |
| カベキック | アクション | コインはトゲのすぐそば。待てば狙えるが溶岩は待たない |
| ジントリ | ストラテジー | 兵を半分送れば陣地が取れる。送ったぶん自陣は手薄 |
| ピカピカ | 作業・育成 | こすって稼ぎ、道具を買うと、こするのが楽になる |
| ヨクバリ | 運だめし | 深くもぐるほど宝は増える。サメに会えば袋は空 |
| カッキーン | スポーツ | フルスイングは飛距離 1.5 倍、判定はずっと狭い |
| スベール | すべるパズル | 止まれないペンギンを岩を使って魚へ。詰んだら自動で戻る |
| シワケ | 反射 | 急ぐほどコンボで点が伸びる。まちがえれば全部失う |

## 作り

- `lib.js`：360×640 のキャンバス、入力、効果音（Web Audio の合成音）、ヒットストップ・画面振動・フラッシュ・
  パーティクル、タイトル → プレイ → 結果 → タップで即リトライ、ベスト記録（localStorage）
- `games/*.js`：1 本 1 ファイル。先頭の `T` に調整値をまとめてある（数値を変えるだけで手触りを変えられる）
- `play.html?g=名前` で各ゲームを読み込む

設計の点検に [kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（非公式のまとめ）を使った。
取り入れたのは主に次の点：核を一言で言える／タップ 1 回で開始し説明はプレイ中に出す／
ヒットストップと効果音を全ゲームに入れる／やられてから再開までを短く／色だけでなく形でも見分けられる／
調整値をコードの外側（先頭）に出す。

絵と音はすべて仮（図形と合成音）。難易度は人の手で遊んで詰めていない。
